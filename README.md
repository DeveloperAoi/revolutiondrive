# REVOLUTION DRIVE: FIRST IGNITION — Official Website

HTML / CSS / JavaScript で構成された静的サイトです。GitHub Pagesで公開できます。

## ファイル構成

- `index.html` — HOME
- `game.html` — GAME
- `cars.html` — CARS
- `courses.html` — COURSES
- `news.html` — NEWS
- `news-detail.html` — NEWS DETAIL
- `faq.html` — FAQ
- `privacy.html` — PRIVACY POLICY
- `assets/css/style.css` — 共通スタイル
- `assets/js/main.js` — 共通スクリプト

## ローカル確認

`index.html` をブラウザで開いてください。推奨は VS Code の Live Server です。

## GitHub Pagesで公開

1. GitHubで新しいPublicリポジトリを作成
2. このフォルダ内のファイルとフォルダをリポジトリ直下にアップロード
3. Settings → Pages
4. Build and deployment を `Deploy from a branch` に設定
5. Branch を `main`、Folder を `/ (root)` にして Save

## 公開前に確認すること

- 外部画像URLはサンプル画像です。使用権・表示品質を確認し、必要に応じて権利処理済みの画像へ差し替えてください。
- 車両・コース・発売日・価格など未確定情報は断定していません。
- Privacy Policy は現状のサイト構成に合わせた初期文案です。実際の運営・解析・問い合わせ機能に合わせて更新してください。
- サイト内のニュースは初期サンプルです。公開前に実際の告知内容へ編集してください。
